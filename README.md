# Fantasy Football Edge

Fantasy Football Edge is a personal-use fantasy football dashboard currently in development.

The application is designed to display fantasy football information on a dedicated desktop display, providing an at-a-glance view of weekly fantasy matchups while games are being played.

## Features

Fantasy Football Edge is being developed to display read-only fantasy football information including:

- League and team information
- Weekly matchups
- Live fantasy scoring
- Player scoring
- Rosters and starting lineups
- Projected scores
- Matchup status and related fantasy information

## Yahoo Fantasy Sports Integration

Fantasy Football Edge intends to use the official Yahoo Fantasy Sports API to retrieve authorized fantasy football information.

Yahoo integration will be:

- Read-only
- Accessed through authorized Yahoo API authentication
- Limited to fantasy information authorized by the user
- Used only to display fantasy football information
- Compliant with applicable Yahoo API requirements

Fantasy Football Edge will not use the Yahoo Fantasy Sports API to make roster changes, add or drop players, submit transactions, or perform other write actions.

## Project Status

Fantasy Football Edge is currently an early-stage personal project and is not publicly distributed or monetized.

The application runs locally on a Windows PC and is being developed for use with a dedicated desktop display.

## Privacy

Fantasy Football Edge does not sell user data. Authentication credentials and tokens used during development are stored locally and are not included in this repository.
